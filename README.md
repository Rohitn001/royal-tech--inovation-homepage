# Royal Tech Innovation — Homepage Concept

A responsive, beginner-friendly HTML/CSS company homepage created as a UI/UX and front-end interview practice project.

## Files
- `index.html` — page structure and small mobile navigation script
- `style.css` — styling and responsive layouts

## Run locally
Open `index.html` in a browser. The page uses Google Fonts when internet is available; the design otherwise falls back to system fonts.

## Before publishing
This is a concept, not verified company information. Confirm the company's actual services, contact details, logo, and claims before using it as an official website. Replace `hello@example.com` with an approved contact email.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, e.g. `royal-tech-innovation-homepage`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL to appear in the Pages section.
